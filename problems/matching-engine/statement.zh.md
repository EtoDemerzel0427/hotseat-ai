# 撮合引擎

实现一个内存中的撮合引擎。它从标准输入逐行读取订单消息，按顺序处理，发生成交时立即输出；输入结束后输出每个品种订单簿的快照。

## 规则

**订单簿。** 尚未成交、留在系统里等待的订单组成订单簿。每个品种（`symbol`）有自己的一本簿，不同品种之间互不成交。一本簿分两侧：买单组成买盘，卖单组成卖盘。

**限价单。** 每笔订单带一个限价：买单表示"不高于这个价格买入"，卖单表示"不低于这个价格卖出"。

**撮合。** 新订单进入引擎时，先和对手盘撮合：

- 买单可以和价格不高于自己限价的卖单成交；卖单可以和价格不低于自己限价的买单成交。
- 价格优先：买单先和最低的卖价成交，卖单先和最高的买价成交。
- 时间优先：同一价位上，先进入订单簿的订单先成交。
- 成交价取簿上那笔订单（被动方）的价格，不是新订单（主动方）的限价。
- 每次成交的数量是双方剩余数量中较小的那个。新订单可以连续和多笔订单、多个价位成交。

撮合结束后，新订单如果还有剩余数量，就以自己的限价挂入本方的订单簿，排在同价位已有订单的后面。

## 输入

每行一条消息，字段用空格分隔。空行忽略。

```
INSERT <id> <symbol> <BUY|SELL> <price> <qty>
```

- `id`：64 位无符号正整数。
- `symbol`：非空的大写字母串。
- `price`：正的十进制数，整数部分 1 到 12 位，小数部分最多 2 位。`100`、`100.5`、`100.25` 都是合法写法。
- `qty`：1 到 10^9 的整数。

本阶段保证所有消息都合法，`id` 互不相同。消息总数不超过 10^5。

## 输出

每发生一笔成交，立即输出一行：

```
TRADE <symbol> <price> <qty> <主动方 id> <被动方 id>
```

输入结束后，按品种名的字典序输出每一本仍有挂单的订单簿。没有挂单的品种不输出。

```
BOOK <symbol>
BID <price> <该价位总数量> <该价位订单数>
ASK <price> <该价位总数量> <该价位订单数>
```

`BID` 行从最高买价到最低买价，然后是 `ASK` 行，从最低卖价到最高卖价。每个价位一行。

所有输出的价格保留两位小数。

## 样例 1

输入

```
INSERT 1 AAPL BUY 100.00 10
INSERT 2 AAPL SELL 101.00 5
```

输出

```
BOOK AAPL
BID 100.00 10 1
ASK 101.00 5 1
```

买单最多出 100，卖单最少要 101，无法成交，两笔都留在簿上。

## 样例 2

输入

```
INSERT 1 AAPL SELL 101 5
INSERT 2 AAPL SELL 100 5
INSERT 3 AAPL SELL 100 5
INSERT 4 AAPL SELL 102 5
INSERT 5 AAPL BUY 101 12
```

输出

```
TRADE AAPL 100.00 5 5 2
TRADE AAPL 100.00 5 5 3
TRADE AAPL 101.00 2 5 1
BOOK AAPL
ASK 101.00 3 1
ASK 102.00 5 1
```

买单 #5 先吃最低的卖价 100：这个价位上 #2 先到，#3 后到，依次成交。然后吃 101 这一档的 #1，成交 2 手后 #5 的 12 手全部成交。#1 剩下 3 手留在簿上。
