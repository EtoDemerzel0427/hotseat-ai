# 阶段 3：固定数量的机器

机器数量现在是固定的 `K` 台。每台机器同一时刻只能执行一个任务，任务开始后不能中断，也不能换机器。

一个任务处于"就绪"状态，是指它还没有开始，并且它依赖的所有任务都已完成。调度器按下面的规则工作：

1. 时刻 `0` 时所有机器空闲。
2. 在任意时刻 `t`，先处理完成：所有在时刻 `t` 结束的任务完成，它们占用的机器变为空闲，依赖它们的任务可能因此变为就绪。
3. 然后处理开始：只要有空闲的机器并且有就绪的任务，就让编号最小的就绪任务在时刻 `t` 开始，占用一台空闲机器。重复这一步，直到没有空闲机器或没有就绪任务。

也就是说，只要有就绪任务，机器就不会空着等待。按这个规则得到的总完成时间不一定是所有调度方案中最短的，你只需要输出按这个规则执行的结果。

## 输入

在阶段 2 的输入之后，增加一行：

```
WORKERS K
```

如果输入中没有 `WORKERS` 这一行，就是阶段 1 或阶段 2 的输入，按对应阶段的要求输出。`WORKERS` 只会出现在有 `DURATION` 段的输入中。

## 输出

格式与阶段 2 相同。如果依赖关系中存在环，输出一行 `CYCLE`。

否则输出两行：

- 第一行一个整数：按上述规则执行时，全部任务完成的时刻。
- 第二行 `N` 个整数：任务 `1` 到 `N` 各自的开始时刻，用一个空格分隔。

## 数据范围

- `1 ≤ K ≤ 10^5`
- 其余与阶段 2 相同。

## 样例 1

输入

```
5 4
1 3
2 3
3 5
4 5
DURATION
3 2 4 6 1
WORKERS 2
```

输出

```
9
0 0 3 2 8
```

解释：时刻 0 就绪的任务是 1、2、4，只有两台机器，编号小的 1 和 2 先开始。时刻 2 任务 2 完成，空出一台机器，就绪的只有任务 4，它在时刻 2 开始，时刻 8 完成。时刻 3 任务 1 完成，任务 3 变为就绪并开始，时刻 7 完成。时刻 7 任务 5 还在等任务 4。时刻 8 任务 4 完成，任务 5 开始，时刻 9 完成。

## 样例 2

输入

```
3 1
3 1
DURATION
2 2 5
WORKERS 1
```

输出

```
9
7 0 2
```

解释：只有一台机器。时刻 0 就绪的是任务 2 和 3（任务 1 依赖任务 3），先执行任务 2。时刻 2 就绪的只有任务 3，执行到时刻 7。然后执行任务 1，时刻 9 完成。
