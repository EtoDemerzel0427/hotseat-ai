# 带依赖的任务调度

一个构建系统里有 `N` 个任务，编号 `1` 到 `N`。任务之间有依赖关系：依赖对 `a b` 表示任务 `a` 必须在任务 `b` 开始之前完成。

现在只有一台机器，任务只能一个接一个地执行。请给出一个执行顺序，使得每个任务执行时，它依赖的所有任务都已经完成。

## 规则

合法的顺序可能有很多个，按下面的规则确定唯一的一个：每一步，在所有尚未执行、并且依赖的任务都已执行完的任务中，选编号最小的那个执行。

如果依赖关系中存在环，就不存在合法的顺序，此时输出 `CYCLE`。

## 输入

第一行两个整数 `N M`，表示任务数和依赖对的数量。

接下来 `M` 行，每行两个整数 `a b`，表示任务 `a` 必须在任务 `b` 之前完成。同一个依赖对可能出现多次。

## 输出

如果存在合法顺序，输出一行 `N` 个整数，是按上述规则得到的执行顺序，用一个空格分隔。

否则输出一行 `CYCLE`。

## 数据范围

- `1 ≤ N ≤ 10^5`，`0 ≤ M ≤ 2×10^5`
- `1 ≤ a, b ≤ N`，`a ≠ b`

## 样例 1

输入

```
6 5
5 1
5 2
3 4
6 3
2 4
```

输出

```
5 1 2 6 3 4
```

解释：一开始没有未完成依赖的任务是 5 和 6，选编号小的 5。5 完成后，1 和 2 可以执行，此时可选的是 1、2、6，选 1，然后选 2。接下来可选的只有 6（任务 4 还在等任务 3）。6 完成后执行 3，最后执行 4。

## 样例 2

输入

```
4 4
1 2
2 3
3 2
3 4
```

输出

```
CYCLE
```

解释：任务 2 和任务 3 互相等待对方完成。
