# 阶段 2：任务耗时与并行执行

现在每个任务有一个耗时，并且机器数量不限：任意多个任务可以同时执行。一个任务可以开始的条件不变：它依赖的所有任务都已完成。任务一旦开始就连续执行到结束，耗时为 `d` 的任务在时刻 `s` 开始，则在时刻 `s + d` 完成。依赖的任务在时刻 `t` 完成，后续任务最早可以在时刻 `t` 开始。

所有任务从时刻 `0` 起可以开始。求全部任务完成的最早时刻，以及每个任务的最早开始时刻。

## 输入

在阶段 1 的输入之后，增加两行：

```
DURATION
d1 d2 ... dN
```

第一行是固定的单词 `DURATION`，第二行是 `N` 个整数，`di` 是任务 `i` 的耗时。

如果输入中没有 `DURATION` 这一段，就是阶段 1 的输入，按阶段 1 的要求输出。

## 输出

如果依赖关系中存在环，输出一行 `CYCLE`。

否则输出两行：

- 第一行一个整数：全部任务完成的最早时刻。
- 第二行 `N` 个整数：任务 `1` 到 `N` 各自的最早开始时刻，用一个空格分隔。

## 数据范围

- `1 ≤ di ≤ 10^9`
- 其余与阶段 1 相同。

## 样例 1

输入

```
5 4
1 3
2 3
3 5
4 5
DURATION
3 2 4 6 1
```

输出

```
8
0 0 3 0 7
```

解释：任务 1、2、4 没有依赖，在时刻 0 开始。任务 3 要等任务 1（时刻 3 完成）和任务 2（时刻 2 完成），在时刻 3 开始，时刻 7 完成。任务 5 要等任务 3（时刻 7）和任务 4（时刻 6），在时刻 7 开始，时刻 8 完成。

## 样例 2

输入

```
3 3
1 2
2 3
3 1
DURATION
5 5 5
```

输出

```
CYCLE
```
