# 表达式计算器

实现一个整数表达式计算器。输入的每一行是一个表达式，对每一行输出它的值。

## 规则

表达式由以下几种符号组成：

- 非负十进制整数，例如 `0`、`42`。除了 `0` 本身，不会有前导零。
- 二元运算符 `+`、`-`、`*`、`/`。
- 一元负号 `-`，写在操作数前面，表示取相反数。一元负号可以连续出现，例如 `- -3` 的值是 `3`。
- 空格。空格可以出现在任意两个符号之间，也可以出现在行首和行尾，数量不限，也可以没有。一个整数的各位数字之间不会有空格。

运算顺序：

- 一元负号的优先级最高，其次是 `*` 和 `/`，最后是 `+` 和 `-`。
- 同一优先级的二元运算符从左到右结合。例如 `10 - 4 - 3` 的值是 `3`，`100 / 7 / 2` 的值是 `7`。
- 表达式里没有自增自减运算符，`2 --3` 表示 `2 - (-3)`。

除法是整数除法，结果向零取整：`7 / 2` 是 `3`，`-7 / 2` 是 `-3`，`7 / -2` 是 `-3`，`-7 / -2` 是 `3`。

如果计算一个表达式的过程中出现了除数为 0 的除法，这一行的结果是 `ERROR`。表达式的每个部分都会被计算，不存在短路，例如 `5 / 0 * 0` 的结果是 `ERROR`。

## 输入

若干行，读到输入结束为止。每行是一个符合上述规则的表达式。输入保证语法合法，不会有空行。

## 输出

对每一行输入输出一行：表达式的值（十进制整数，负数带 `-`，零输出 `0`），或者 `ERROR`。

## 数据范围

- 行数不超过 `1000`，每行长度不超过 `10^4` 个字符。
- 连续出现的一元负号不超过 `10` 个。
- 表达式中的每个整数，以及每个能正常算出结果的子表达式的值，绝对值都不超过 `10^18`，可以用 64 位有符号整数表示。

## 样例 1

输入

```
1 + 2 * 3
10 - 4 - 3
7 / 2
-7 / 2
2 * -3
- -3
5 / 0
   42
```

输出

```
7
3
3
-3
-6
3
ERROR
42
```

解释：第 1 行先算乘法。第 2 行从左到右，`(10 - 4) - 3 = 3`。第 4 行 `-7 / 2` 的数学结果是 `-3.5`，向零取整得 `-3`。第 5 行的 `-` 紧跟在 `*` 后面，是一元负号。第 7 行除数为 0。

## 样例 2

输入

```
3+4*2-10/4
  100 / 7 / 2
7 / -2
2 --3
1 - 2 * 3 + 4 / 0
0 / 5
```

输出

```
9
7
-3
5
ERROR
0
```

解释：第 1 行没有空格，值是 `3 + 8 - 2 = 9`（`10 / 4` 向零取整得 `2`）。第 2 行从左到右，`100 / 7 = 14`，`14 / 2 = 7`。第 4 行是 `2 - (-3)`。第 5 行里有除数为 0 的除法，整行是 `ERROR`。第 6 行被除数是 0，除数不是 0，结果是 `0`。
