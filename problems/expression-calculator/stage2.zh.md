# 阶段 2：括号

表达式里现在可以出现圆括号 `(` 和 `)`。括号内是一个完整的表达式，先算出它的值，再作为一个操作数参与外层运算。括号可以任意嵌套，前面可以有一元负号，例如 `-(3 + 4)` 的值是 `-7`。

括号保证成对匹配，括号内不会为空。其余规则与阶段 1 相同，括号内出现除数为 0 时整行结果仍是 `ERROR`。

## 数据范围

- 括号的嵌套深度不超过 `100`。
- 其余与阶段 1 相同。

## 样例 1

输入

```
2 * (3 + 4)
-(3 + 4)
((((5))))
(1 + 2) * (3 - 7) / 5
( 8 - 3 ) / -( 1 + 1 )
10 / (5 - 5)
2 - (3 - (4 - (5 - 6)))
```

输出

```
14
-7
5
-2
-2
ERROR
4
```

解释：第 4 行是 `3 * (-4) / 5 = -12 / 5`，向零取整得 `-2`。第 5 行是 `5 / -2`，向零取整得 `-2`。第 6 行括号内的值是 0，作为除数，结果是 `ERROR`。

## 样例 2

输入

```
((2 + 3) * (4 - 1) - 1) / 7
-(-(-2))
1 - (2 - 3) - (4 - 5)
6 / (1 - 3) * (2 + 1)
(1 + 2) / (3 - 3) + (4 * 5)
```

输出

```
2
-2
3
-9
ERROR
```

解释：第 1 行是 `(5 * 3 - 1) / 7 = 14 / 7`。第 3 行是 `1 - (-1) - (-1)`。第 4 行从左到右，`6 / -2 = -3`，再乘 `3`。第 5 行的除数 `(3 - 3)` 为 0。
