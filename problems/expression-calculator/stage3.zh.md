# 阶段 3：变量

计算器现在支持变量。输入的每一行是下面两种形式之一：

- 表达式：与之前相同，输出它的值。
- 赋值语句 `name = expr`：计算右边的表达式，把结果存入变量 `name`，并输出这个值。

变量名由字母、数字和下划线组成，第一个字符不是数字，区分大小写。变量名可以作为操作数出现在表达式里（包括赋值语句的右边），它的值是该变量当前存的值。变量在各行之间保持，后面的赋值会覆盖前面的值。`=` 两侧可以有任意多个空格，也可以没有。一行里最多有一个 `=`，并且只会出现在行首的变量名之后。

错误处理：

- 表达式里用到了尚未赋值的变量，这一行的结果是 `ERROR`。
- 赋值语句右边的结果是 `ERROR`（除数为 0，或用到未赋值的变量）时，这一行输出 `ERROR`，并且不做赋值：变量原来有值就保持原值，原来没有值就仍然是未赋值状态。
- `x = x + 1` 这样的语句，右边的 `x` 取赋值之前的值；如果此前 `x` 未赋值，结果是 `ERROR`。

## 数据范围

- 变量名长度不超过 `20`，不同的变量不超过 `1000` 个。
- 变量的值与其他子表达式一样，绝对值不超过 `10^18`。
- 其余与阶段 2 相同。

## 样例 1

输入

```
x = 5
y = x * 2 + 1
x + y
z
x = x - 10
y / x
w = 1 / 0
w
```

输出

```
5
11
16
ERROR
-5
-2
ERROR
ERROR
```

解释：第 4 行的 `z` 没有赋过值。第 5 行右边用的是 `x` 的旧值 5，赋值后 `x` 是 `-5`。第 6 行是 `11 / -5`，向零取整得 `-2`。第 7 行右边出错，所以 `w` 没有被赋值，第 8 行使用 `w` 仍然是 `ERROR`。

## 样例 2

输入

```
a=10
A = a * a
a_2 = (A - a) / -4
a + A + a_2
a = a / (A - 100)
a
b = b + 1
b = 0
b = b + 1
```

输出

```
10
100
-22
88
ERROR
10
ERROR
0
1
```

解释：`a` 和 `A` 是两个不同的变量。第 3 行是 `90 / -4`，向零取整得 `-22`。第 5 行右边除数为 0，赋值没有发生，所以第 6 行的 `a` 仍然是 `10`。第 7 行右边用到了尚未赋值的 `b`。
